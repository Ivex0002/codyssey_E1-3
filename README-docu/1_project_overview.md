# 프로젝트 개요

## 1. 프로젝트 소개

**Mini NPU Simulator**는 인공지능의 패턴 인식 과정에서 사용되는 MAC(Multiply-Accumulate) 연산을 Python으로 구현하고, 간단한 패턴 분류 과정을 시뮬레이션하는 프로젝트이다.

입력 패턴과 두 종류의 필터(Cross, X)를 위치별로 곱하고 누적하여 각각의 점수를 계산한다. 이후 두 점수를 비교하여 입력 패턴이 어떤 형태에 가까운지 판정한다.

외부 연산 라이브러리 없이 Python의 반복문을 이용해 MAC 연산을 직접 구현하며, 다양한 크기의 행렬을 대상으로 연산 결과와 실행 시간을 분석한다.

## 2. 주요 기능

### 2.1 사용자 입력 기반 패턴 분석
- 3×3 필터 A, B 및 입력 패턴을 직접 입력할 수 있다.
- 패턴 생성기를 통해 원하는 크기의 Cross 및 X 패턴을 생성할 수 있다.
- MAC 연산을 수행하여 두 필터의 점수를 계산한다.
- 점수 비교를 통해 입력 패턴을 판정한다.

### 2.2 JSON 데이터 기반 패턴 분석
- `data/data.json`에서 필터와 테스트 패턴을 불러온다.
- `data.json`에 존재하는 필터들의 키값을 파싱하여 같은 크기의 필터를 매칭하여 동적인 계산을 지원한다.
- 패턴별 정답(Expected)과 실제 판정 결과를 비교한다.
- 각 테스트의 PASS/FAIL 여부와 전체 테스트 결과를 출력한다.

### 2.3 MAC 연산 및 결과 판정
- 입력 패턴과 필터의 동일한 위치에 있는 값을 곱하고 누적한다.
- 두 필터의 최종 점수를 비교하여 Cross 또는 X로 판정한다.
- 부동소수점 연산의 오차를 고려하여 epsilon 기반 동점 판정 정책을 적용한다.
- 점수가 동일하거나 허용오차 범위 내에 있으면 판정 불가(UNDECIDED)로 처리한다.

### 2.4 성능 측정 및 분석
- MAC 연산을 반복 실행하여 평균 처리 시간을 측정한다.
- 연산 시간은 밀리초(ms) 단위로 출력한다.
- 행렬 크기별 연산 횟수(N²)와 평균 실행 시간을 비교한다.
- 1차원 배열(1D)과 2차원 배열(2D) 처리 방식을 선택하여 성능 차이를 분석할 수 있다.

## 3. 핵심 연산 원리

MAC(Multiply-Accumulate)은 곱셈과 누적 덧셈을 결합한 연산 방식이다.

입력 행렬과 필터 행렬의 동일한 위치에 있는 값을 곱한 뒤 모든 결과를 누적한다.

\[
Score = \sum_{i=0}^{N-1}\sum_{j=0}^{N-1}
Input_{i,j}\times Filter_{i,j}
\]

두 필터의 점수를 각각 계산한 후 더 높은 점수를 가진 필터를 최종 판정 결과로 선택한다.

## 4. 프로그램 실행 구조

프로그램은 크게 두 가지 분석 방식으로 구성된다.

1. **사용자 입력 모드**
   - 필터 및 패턴 입력
   - 입력 데이터 검증
   - MAC 연산 수행
   - 결과 판정 및 성능 측정

2. **JSON 데이터 분석 모드**
   - JSON 데이터 로드
   - 필터 및 패턴 데이터 검증
   - 패턴별 MAC 연산 수행
   - 정답 비교 및 PASS/FAIL 판정
   - 크기별 성능 분석 및 결과 요약

추가로 배열 평탄화 모드를 제공하여 연산에 사용되는 데이터 구조를 변경할 수 있다.

## 5. 프로젝트 목표

본 프로젝트의 목표는 MAC 연산의 기본 원리를 이해하고 직접 구현하는 것이다.

이를 통해 행렬 기반 연산과 패턴 분류의 관계를 이해하고, 입력 데이터의 크기 및 배열 구조에 따른 연산 성능 차이를 확인한다.

궁극적으로 단순한 패턴 분류 시뮬레이터를 구현함으로써 NPU와 같은 인공지능 연산 장치의 기초적인 연산 구조를 학습하는 데 목적이 있다.
